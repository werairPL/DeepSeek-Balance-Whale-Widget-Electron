# DeepSeek-Balance-Whale-Widget-Electron

本仓库基于：https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget

仅进行了桌面常驻化，其他功能完全不变。API KEY由本地读取

如果你在桌面部署过deepseekharness直接启动即可正常使用，若使用的是第三方客户端则需要手动配置
**推荐直接在"C:\Users\你的用户名\.dsh"目录下创建一个名为".credentials.yaml"的文件，在第一行直接写入:"DEEPSEEK_API_KEY: 你的APIKEY"即可（不包括引号）**
